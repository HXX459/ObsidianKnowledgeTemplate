# 计算机科学学习知识库模板

这是一份可以独立放在 GitHub、复制成新 Obsidian 知识库的**计算机科学学习样板**。顶层记录学习过程、项目与个人理解；`04-Resources` 用计算机网络、操作系统、数据库、软件系统架构展示主题知识树。示例页面只提供问题与写法，不预设课程进度或已掌握的结论。

## 从哪里开始

1. 先读 [知识库地图](知识库地图.md)，确定一条内容放在哪里。
2. 打开 [Resources 主题索引](04-Resources/README.md)，看“目录树 + 叶子页面 + 跨主题链接”的组织方式。
3. 如果要让 Codex 基于此创建新库，交给它 [搭建指南](GUIDE-交给Codex.md)，并告诉它目标位置、要保留或扩展的计算机主题、已有内容的位置。

## 作为 GitHub 模板使用

将 **Base 目录内的内容**放在独立仓库的根目录，然后在 GitHub 将该仓库设为模板仓库。使用者从模板创建新仓库后，把该仓库文件夹作为 Obsidian vault 打开即可；Markdown 相对链接不依赖当前电脑路径。发布前可自行选择许可证并检查是否包含私人笔记或附件。

此样板没有预装插件或 `.obsidian` 配置；使用者可在新库中按需配置。若仓库只用来分享模板，不必为四个示例主题填满知识正文。

## 工作分区

| 目录 | 作用 |
| --- | --- |
| [00-Inbox](00-Inbox/README.md) | 讨论中的临时小结、片段与待追问问题 |
| [01-Projects](01-Projects/README.md) | 有目标、交付物和结束条件的项目 |
| [02-Areas](02-Areas/README.md) | 长期维护的目标、能力、责任和方向 |
| [03-Notes](03-Notes/README.md) | 自己形成的、可独立复用的观点 |
| [04-Resources](04-Resources/README.md) | 按主题编排的知识页面、文章、视频和资料笔记 |
| [05-Journal](05-Journal/README.md) | 日志、周回顾和值得保留的讨论过程 |
| [06-Archive](06-Archive/README.md) | 已结束项目和历史资料 |
| [99-Meta](99-Meta/README.md) | 模板、约定和附件位置 |

这些是内容的**用途分区**。具体学科和知识分类主要长在 `04-Resources` 内，不需要为每个新主题增加顶层目录。

## 样板的边界

- 示例页只是展示计算机科学目录与写法，页面中没有声称已读资料或已验证结论。
- Markdown 相对链接用于保证这份骨架在 `Base` 内和复制后的新库中都能使用。
- 不依赖 Dataview、Templater 或其他社区插件；没有复制现有仓库的 `.obsidian` 设置。
- 此目录位于当前知识库内。将来搭建新库时，复制 **Base 内的内容**到新库根目录，避免出现 `新库/Base/...` 的额外一层。

## 最小使用循环

讨论临时记录 → 按用途整理 → 学习或实践 → 写下证据与疑问 → 形成自己的判断 → 在相关页面之间建立链接。需要什么页面，就创建什么页面；不为填满目录而预建空笔记。
