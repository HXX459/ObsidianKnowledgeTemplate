# 03-Notes · 个人观点

一页记录一个自己形成的主张，并写明理由、证据、反例和适用边界。可以来自文章、视频、项目或讨论，但不能把别人的结论直接冒充为个人观点。

未形成独立判断时，先写在 [Resources](../04-Resources/README.md) 的学习页面；暂时的想法放 [Inbox](../00-Inbox/README.md)。只有观点值得单独复用时，才需要从原学习笔记中提炼。

使用 [个人观点模板](../99-Meta/Templates/T-个人观点.md)。
