# 05-Journal · 过程记录

按时间记录做过的事、学到的事、卡点与下一步。可按需要建立 `Daily/YYYY-MM/`、`Weekly/YYYY/` 或 `Discussions/`；没有实际记录前，不预建日期文件。

一时的讨论草稿放 [Inbox](../00-Inbox/README.md)；讨论过程本身具有长期价值时，再整理进这里。知识解释和个人判断仍回到 Resources 或 Notes，并从日志链接过去。

使用 [复盘模板](../99-Meta/Templates/T-复盘.md)。
