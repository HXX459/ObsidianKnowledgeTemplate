# 99-Meta · 模板与约定

本目录放通用模板，不包含任何 Obsidian 社区插件配置。模板中的 `（填写…）` 是人工替换提示；插入模板后按内容删减空栏，不必为了填满模板制造内容。

| 模板 | 用途 |
| --- | --- |
| [临时讨论](Templates/T-临时讨论.md) | 暂存讨论背景、阶段小结与待追问问题 |
| [项目](Templates/T-项目.md) | 有交付物的实践 |
| [长期领域](Templates/T-长期领域.md) | 长期维护目标与状态 |
| [个人观点](Templates/T-个人观点.md) | 一个独立的主张及其证据 |
| [主题页](Templates/T-主题页.md) | 知识树中的叶子问题页面 |
| [资料卡](Templates/T-资料卡.md) | 待读或已读文章、视频、课程、论文入口 |
| [复盘](Templates/T-复盘.md) | 周回顾或阶段复盘 |

## 记录约定

- 内容页面建议填写 `title`、`summary`、`type`、`status`、`created`、`updated`。日期使用 `YYYY-MM-DD`。
- `status: example` 专用于样板示例；真实笔记可以改为 `unread`、`draft`、`growing`、`verified` 或 `archived`，但应明确每个状态的含义。
- 摘要用两三句话说明“这页回答什么、包含什么”，不要把空页面描述为已完成的知识。
- 外部材料写原始来源、作者和查阅日期；未实际阅读时保留“待读”。事实、推断与亲自验证的结果分开写。
- 项目结果和复盘只根据实际发生的工作填写；计算机主题示例不代表已经完成学习或实验。
- 附件可放 `99-Meta/Attachments/` 或外部资料库，正文保存相对路径和来源。目标库建立时再决定实际附件位置。

复制到新知识库后，可以按使用者的 Obsidian 设置将模板改成核心 Templates 或 Templater 语法。样板本身不要求插件。
