## 添加新主题

1. 先明确要回答的一组计算机问题，再建立一个主题目录与 `00-导览-主题.md`。新的主题可以是算法、编译原理、分布式系统、安全等，按实际学习需要增加。
2. 内容多到需要分组时再建一层分支；一般不超过四层路径。
3. 每个叶子页写清标题、两三句内容简介、来源、自己的理解、未解决问题和相关页面。
4. 文章或视频未看完可以先建资料卡，标“待读”；真正读完再补理解，不把链接收藏等同于学习。
5. 同一页面可能属于两类时，只保留一份正文，从另一主题导览链接过去。

通用写法见 [主题页模板](../99-Meta/Templates/T-主题页.md) 和 [资料卡模板](../99-Meta/Templates/T-资料卡.md)。示例叶子页只展示结构。
