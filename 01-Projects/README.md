# 01-Projects · 项目

一项工作有具体交付物和验收条件时，在此建立项目目录。主文档记录背景、目标、范围、里程碑、关键决策、成果和复盘；过程文件可放同一目录。

例如“为一个小服务完成架构方案”或“实现并测试一个数据库查询工具”是项目；长期提升系统设计能力属于 Areas。这里没有创建真实项目。

使用 [项目模板](../99-Meta/Templates/T-项目.md)。结束后写复盘，再移到 [归档区](../06-Archive/README.md)。
