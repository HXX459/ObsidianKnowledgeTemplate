# 02-Areas · 长期维护

存放持续维护的学习目标、能力基线和技术方向，例如“计算机基础学习计划”“数据库实践能力”“系统设计能力”。这里的页面主要回答：我现在处于什么状态，接下来怎么调整？

与 [Resources](../04-Resources/README.md) 的区别：Resources 解释一个主题或资料；Areas 管理自己的长期状态。与 [Notes](../03-Notes/README.md) 的区别：Notes 陈述一个可独立引用的判断。

根据实际学习范围创建领域，不预设个人职业或技术水平。使用 [长期领域模板](../99-Meta/Templates/T-长期领域.md)。
