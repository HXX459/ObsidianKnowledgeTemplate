# 00-Inbox · 临时讨论区

存放与 AI 或他人讨论时的阶段小结、必要聊天片段、尚未证实的判断和待追问问题。不默认保存每次聊天全文。

讨论后可以将长期目标更新到 Areas，知识解释整理到 Resources，独立判断提炼到 Notes，项目结论放进相应项目。保留有意义的过程时放进 Journal。临时文件链接最终笔记后，可按需归档。

新建时可使用 [临时讨论模板](../99-Meta/Templates/T-临时讨论.md)。
